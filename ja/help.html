VibeFront ヘルプ

AI搭載HTMLエディタの使い方ガイド

VibeFrontは、AIを搭載したWindows向けデスクトップHTMLエディタです。コードエディタ（AvalonEdit）とリアルタイムプレビュー（WebView2）を組み合わせ、AIによるHTML生成・校正・翻訳・最適化機能を備えています。

クイックスタート

  1. アプリを起動
    Microsoft Storeからインストール後、スタートメニューから「VibeFront」を起動します。アカウント登録は不要です。
  2. AI設定（推奨）
    メニューの AI → AI設定 からお好みのAIプロバイダーとAPIキーを設定します。初めての方は Google Gemini（無料） がおすすめです。
  3. HTMLを編集
    コードを書いてリアルタイムプレビューで確認。AIに「お問い合わせフォームを作って」と頼むこともできます。

AI機能の概要

VibeFrontのAI機能は以下の4社のAIプロバイダーに対応しています。お好みのプロバイダーを1つ設定するだけで、すべてのAI機能（HTML生成、テンプレート、校正、翻訳、最適化、画像→HTML変換）が使えます。

APIキーについて
APIキーはお客様のPC上のみに保存され（%LOCALAPPDATA%\VibeFront\ai_settings.json）、外部には一切送信されません。AI利用時のみ、お客様が選んだプロバイダーに直接送信されます。

以下は、VibeFrontでのHTML編集に適したおすすめのAIモデルです。

初心者へのおすすめ
Google Gemini が最もおすすめです。無料のAPIキーが簡単に取得でき、品質も高く、画像→HTML変換にも対応しています。プライバシーを重視する場合は Ollama（ローカルLLM）がおすすめです。

Google Gemini おすすめ

Google Geminiは、VibeFrontの既定モデル Gemini 3.8 Flash を無料枠で使えるため、初めてAIを使う方に最適です。

APIキーの取得手順

  1. Google AI Studio にアクセスし、Googleアカウントでログインします。
  2. 左メニューの「Get API key」をクリックし、「Create API key」ボタンを押します。
  3. 表示されたAPIキー（AIza... で始まる文字列）をコピーします。
  4. VibeFrontの AI → AI設定 で「Google Gemini」を選択し、コピーしたAPIキーを貼り付けて「保存」を押します。
無料枠について
Gemini 3.8 Flash は無料枠で利用できます。1分・1日あたりのリクエスト上限はGoogleが設定しており変更されることがあるため、最新の値は Google AI Studio でご確認ください。なお、Gemini 3.1 Pro (Preview) は無料枠の対象外（有料枠のみ）です。

OpenAI (ChatGPT)

OpenAIのGPTシリーズは、最も広く使われているAIモデルです。有料ですが、高品質なHTML生成が可能です。

APIキーの取得手順

  1. OpenAI Platform にアクセスし、アカウントを作成またはログインします。
  2. API keys ページで「Create new secret key」をクリックします。
  3. 表示されたキー（sk-...）をコピーします。このキーは二度と表示されないので、安全な場所にも控えてください。
  4. VibeFrontの AI設定 で「OpenAI」を選択し、キーを貼り付けて保存します。
料金について
OpenAI APIは従量課金です。最初に$5〜$10程度のクレジットを追加する必要があります。AI設定でモデルを GPT-6 Luna（gpt-6-luna）にすると非常に安価で、HTML編集での一般的な利用なら月$1以下で済みます。
組織の本人確認（Verify Organization）について
OpenAIでは、組織の本人確認が済んでいないと一部のモデルで応答の逐次表示（ストリーミング）が許可されません。VibeFront v1.3.0 はこの場合、自動で一括表示に切り替えます（応答の生成が終わってからまとめて表示されるため、表示まで少し時間がかかります）。本人確認は OpenAI Platform の組織設定から行えます。

Anthropic (Claude)

Anthropicのクロードは、特にコード生成に優れたAIです。

APIキーの取得手順

  1. Anthropic Console にアクセスし、アカウントを作成します。
  2. API Keys ページで新しいキーを作成し、コピーします。
  3. VibeFrontのAI設定で「Anthropic (Claude)」を選択し、キーを貼り付けて保存します。
料金について
Anthropic APIは従量課金です。既定の Claude Opus 5.5 は最高性能のモデルです。費用を抑えたい場合は、AI設定で Claude Sonnet 5.5 や Claude Haiku 4.5 を選んでください。v1.3.0 からプロンプトキャッシュに対応したため、同じ会話で続けて（5分以内に）送信すると、それまでの会話の再送分が割安になります（会話がごく短い場合は対象外です）。

Ollama（ローカルLLM） 完全無料・オフライン

Ollama を使うと、AIモデルをお使いのPC上で直接動かせます。インターネット接続不要で、データが外部に送信されることは一切ありません。APIキーも不要です。

必要なPCスペック
8Bパラメータモデル（推奨）: RAM 8GB以上、GPU搭載PCならさらに高速。一般的なノートPCでもCPUのみで動作可能です（やや遅くなります）。

Ollamaの導入手順

  1. Ollamaをインストール
    ollama.com/download からWindows版をダウンロードしてインストールします。インストーラーの指示に従うだけでOKです。
  2. AIモデルをダウンロード
    コマンドプロンプト（またはPowerShell）を開いて、以下のコマンドを実行します：

    ollama pull qwen3:8b

    初回は数GBのダウンロードが発生します（Wi-Fi環境推奨）。ダウンロードが完了すれば、以降はオフラインで使えます。
  3. Ollamaを起動
    Ollamaは通常、インストール後に自動で起動しています（タスクトレイにアイコンが表示されます）。起動していない場合は、スタートメニューから「Ollama」を起動してください。
  4. VibeFrontで設定
    VibeFrontの AI → AI設定 で以下のように設定します：

    プロバイダーOpenAI互換
    ベースURLhttp://localhost:11434
    モデルIDqwen3:8b
    APIキー空欄でOK
  5. 接続テスト
    「接続テスト」ボタンを押して「接続成功!」と表示されれば設定完了です。

qwen3:8b おすすめ

ollama pull qwen3:8b

ollama pull phi3:3.8b

LM Studio（ローカルLLM） GUI操作・初心者向け

LM Studio は、ローカルLLMをGUI（グラフィカルな画面）で簡単に管理・実行できるアプリです。コマンド操作に不慣れな方に特におすすめです。

LM Studioの導入手順

  1. LM Studioをインストール
    lmstudio.ai からダウンロードしてインストールします。
  2. モデルをダウンロード
    LM Studioを起動し、検索バーに「Qwen3 8B」と入力。表示されたモデル（GGUF形式）のダウンロードボタンを押します。「Q4_K_M」がバランスの良い選択です。
  3. サーバーを起動
    左メニューの「Local Server」タブをクリック → ダウンロードしたモデルを選択 → 「Start Server」ボタンを押します。画面に http://127.0.0.1:1234 と表示されればOKです。
  4. VibeFrontで設定
    VibeFrontの AI設定 で以下のように設定します：

    プロバイダーOpenAI互換
    ベースURLhttp://localhost:1234
    モデルID（LM Studioに表示されているモデル名）
    APIキー空欄でOK
  5. 接続テストで確認
    「接続テスト」をクリックして成功すれば完了です。
OllamaとLM Studioの違い
Ollama: コマンドライン操作。軽量でバックグラウンド動作に最適。技術に慣れた方向け。
LM Studio: GUI操作。モデルの検索・ダウンロード・起動がすべて画面上でできる。初心者向け。
どちらも無料で、VibeFrontとの設定方法はほぼ同じです。

表示モード

VibeFrontには3つの表示モードがあります。ツールバーのボタンまたは表示メニューから切り替えられます。

分割ビュー（デフォルト）

コードエディタとプレビューを並べて表示。変更がリアルタイムに反映されます。

コードビュー

コードエディタのみ表示。コードに集中したい時に。

プレビュー

プレビューのみ表示。表示結果の確認に。テキストを選択するとソースコードの該当箇所にジャンプします。

パネルはAvalonDockにより自由にドッキング・フローティング・並べ替えが可能です。レイアウトは自動的に保存されます。

Emmet展開

Emmet記法を入力して Tab キーを押すと、HTMLが自動展開されます。

入力 展開結果
div<div></div>
div.container<div class="container"></div>
ul>li*3<ul><li></li><li></li><li></li></ul>
nav>ul>li*5>aナビゲーション構造
div#app>header+main+footerページ骨格
table>tr*3>td*43行4列のテーブル
input[type=email]<input type="email">
p{Hello World}<p>Hello World</p>

プレビュー同期

プレビューでテキストを選択すると、コードエディタの該当箇所に自動でジャンプ・ハイライトされます。「このテキストはどのコードに対応しているの？」がすぐにわかります。

レスポンシブプレビュー機能で、モバイル（375px）・タブレット（768px）・デスクトップ（1200px）の表示を即座に確認できます。表示メニュー → レスポンシブプレビュー から切り替えます。

文字コード（エンコーディング）

VibeFrontは以下のエンコーディングに対応しています。ファイルを開くと自動的に文字コードを検出します。

  • UTF-8 / UTF-8 BOM — 新しいHTMLファイルの標準
  • Shift-JIS — 日本語レガシーHTML
  • EUC-JP — 日本語レガシーHTML（Unix系）
  • UTF-16 LE / BE — Windowsテキストファイル

ステータスバーに現在のエンコーディングが表示されます。クリックするとエンコーディングの変更メニューが表示されます。

FAQ

Q: AI機能は必須ですか？

いいえ。AI設定なしでも、通常のHTMLエディタとしてすべての機能（コード編集、プレビュー、Emmet、テーマ、エンコーディング対応など）をお使いいただけます。

Q: AIのAPIキーの料金はVibeFrontの価格に含まれますか？

いいえ。AIプロバイダーのAPI利用料は別途かかります。ただし、Google Gemini は Gemini 3.8 Flash を無料枠で使え、ローカルLLM（Ollama/LM Studio）は完全無料です。

Q: ローカルLLMでも画像→HTML変換は使えますか？

ローカルLLMのほとんどは画像認識に対応していないため、画像→HTML変換にはGoogle Gemini、OpenAI、またはAnthropicの利用をおすすめします。

Q: データは外部に送信されますか？

AI機能を使用した時のみ、入力テキストがお客様が選んだAIプロバイダーに送信されます。それ以外のデータ（設定、ファイル内容等）が外部に送信されることは一切ありません。ローカルLLMを使えば、AI利用時もデータは一切外部に出ません。

Q: 設定ファイルはどこに保存されますか？

%LOCALAPPDATA%\VibeFront\ に保存されます。Windowsのファイルエクスプローラーのアドレスバーに貼り付けると開けます。

Q: 「出力が上限に達したため、応答が途中で切れています」と表示されました

AIが一度に出力できる量の上限に達したため、応答が最後まで生成されていません。チャットで「続けて」と送信して続きを生成させるか、依頼を小さく分けて（例: ページ全体ではなくセクションごとに）お試しください。

Q: 以前選んでいたAIモデルが一覧にありません

v1.3.0 でAIモデルの一覧を各社の最新モデルに更新しました。提供終了・利用制限されたモデル（GPT-4o、Gemini 2.0 Flash / 2.5 など）を設定していた場合は、同じ価格帯の後継モデルへ自動で切り替わります。別のモデルを使いたい場合は、AI設定からいつでも変更できます。

Q: 「AIが安全上の理由で応答を拒否しました」と表示されました

AIプロバイダーの安全機能が依頼内容を拒否した場合に表示されます。通常のWeb制作の依頼で表示された場合は、依頼内容を言い換えて再度お試しください。

Q: 試用期間が終了するとどうなりますか？（ダウンロード版）

ダウンロード版は15日間お試しいただけます。試用期間の終了後も、HTMLの編集・プレビューは引き続きご利用いただけますが、ファイルの保存とAI機能はライセンスのご購入後にご利用いただけます。Microsoft Store版にはこの制限はありません。
