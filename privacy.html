Privacy Policy

Last updated: March 12, 2026

VibeFront ("the App") is a Windows HTML editor application developed by Mojosoft. We respect your privacy and are committed to protecting your personal information.

Information We Collect

The App does not collect any personal information.

  • No user registration or account creation is required.
  • No usage data or analytics are sent to external servers.
  • All file content being edited is processed entirely on your local PC.

AI Features

When using AI features, the text and images you provide are sent to the AI provider API that you have configured (OpenAI, Anthropic, Google Gemini, or a local LLM). Please review each AI provider's privacy policy regarding how they handle this data.

When using local LLMs (LM Studio, Ollama, etc.), your data never leaves your network.

Locally Stored Data

The App stores the following data only on your local PC (under %LOCALAPPDATA%\VibeFront\):

  • Window position, size, and UI preferences
  • AI provider API key configuration
  • Recent file list
  • Panel docking layout
  • Auto-save temporary files
